# CleanMap Campus

A browser-based waste hotspot reporting and cleanup tracking demo.

## Run
Open `index.html` in a browser with an internet connection. Map tiles and place lookup need internet access. Reports are stored in this browser when local storage is available; this demo does not use a shared production database.

## Note
If place lookup is unavailable, a report is still saved with an approximate pin at the current map centre. Use the map search to find the correct location. Export CSV regularly if browser storage is unavailable.
